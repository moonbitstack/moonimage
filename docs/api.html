moonimage Every format, one door

Format detection, decoding, encoding and animation, all of it delegating to the packages below.

functions
function pub fn decode(bytes : BytesView, format? : @raster.PixelFormat, limits? : @raster.Limits) -> @raster.Image raise @raster.Refused

The image in these bytes, whichever format they are.

Without format the picture comes back in the layout the file itself holds, which is what a second decode or a comparison against the original wants. With it, the picture comes back in the layout a caller is drawing with: a canvas wants Rgba8, a GPU upload of a normal map wants Rgb8, and a block texture's own layout is neither. That is one conversion, and none at all when the file already holds the format asked for.

The limits default to Limits::default(); a caller reading untrusted files should pass Limits::strict() or a tighter record.

function pub fn decode_animation(bytes : BytesView, format? : @raster.PixelFormat, limits? : @raster.Limits) -> @raster.Animation raise @raster.Refused

Every frame in these bytes, whichever format they are.

A format that does not animate comes back as an animation of one frame over the whole canvas, so a caller that only draws animations does not need to branch. format is applied to every frame, for the same reason it exists on decode: a canvas draws in one layout and a file may hold several. A TIFF comes back as one frame a page, and an icon as one frame a size, because both are a sequence of pictures that a caller walking a sequence wants to see.

function pub fn encode(image : @raster.Image, format : @raster.Format) -> Bytes raise @raster.Refused

The image as bytes of the named format, with that format's defaults.

A caller that wants to choose how it is written calls the format's own package, which takes its options record.

Dds is refused: a block-compressed texture is a picture whose blocks were chosen by a search, and this library reads them rather than guessing them.

function pub fn encode_animation(animation : @raster.Animation, format : @raster.Format) -> Bytes raise @raster.Refused

The animation as bytes of the named format, with that format's defaults.

The formats that animate keep every frame; the ones that do not write the first, which is what a viewer of a still image shows.

pub fn Animation::compose(self : Animation) -> Array[Image]

Every frame as a full canvas, in order, with each rule applied as it goes.

The result is what a viewer shows: the same length as frames, each one the whole canvas. This is the expensive way to watch an animation and the only way to see it out of context, which is what a test does.

The canvas is sixteen-bit, so that an eight-bit animation and a sixteen-bit one come out of the same code without either losing its precision.

pub fn Image::blur(self : Image, radius : Double, kernel~ : Kernel = Exact) -> Image

The image blurred with a Gaussian of standard deviation radius.

A radius of zero or less is the image itself, so a caller that computes the radius from a size does not have to check for the case.

kernel chooses how the Gaussian is worked out. Exact convolves with the kernel, which is what the number means; Boxes is the same blur by the arithmetic the rest of the world uses, for a caller comparing against a picture some other library made.

pub fn Image::brightness(self : Image, factor : Double) -> Image

The image with every colour channel multiplied by factor.

One is unchanged, zero is black, and two doubles: this is the linear part of exposure, done on the encoded samples rather than on light, which is what a brightness slider in an editor does.

pub fn Image::composite(self : Image, source : Image, x? : Int32, y? : Int32, opacity? : Double) -> Image

This image with source laid over it, its top-left corner at (x, y).

A source larger than the destination is clipped rather than refused: a watermark is usually placed by a corner rule, and a corner rule that lands one pixel outside is not an error.

opacity scales the source's alpha before it is laid down, which is how a watermark is made faint without being re-encoded.

pub fn Image::contrast(self : Image, factor : Double) -> Image

The image with its contrast scaled about mid-grey.

One is unchanged, zero is flat grey, and above one pushes the samples away from the middle: (sample − 0.5) × factor + 0.5, clamped.

pub fn Image::convert(self : Image, format : PixelFormat) -> Image

The same image, in another sample format.

Colour is preserved as far as the target can hold it: a grey image becomes grey, an image without alpha becomes opaque, and narrowing rounds to nearest.

pub fn Image::crop(self : Image, x : Int32, y : Int32, width : Int32, height : Int32) -> Image raise Refused

The rectangle at (x, y) of the given size, as an image of its own.

Raises when the rectangle does not fit: a crop is a claim about the image, and a crop that reaches outside it is a bug in the caller.

pub fn Image::orient(self : Image, code : Int32) -> Image raise Refused

The image turned the way EXIF orientation code says.

One is the picture as stored and comes back unchanged. A number outside one to eight is refused rather than guessed at: a caller that got the tag wrong wants to hear about it.

pub fn Image::pixel(self : Image, x : Int32, y : Int32) -> Pixel raise Refused

The pixel at a coordinate, in the units every operation works in.

Straight alpha, as stored: an image that says it is premultiplied returns premultiplied samples, because pretending otherwise would be a conversion the caller did not ask for.

pub fn Image::rotate(self : Image, quarters? : Int32) -> Image

The image turned a quarter turn clockwise, quarters times.

Negative counts turn anticlockwise, and anything beyond four wraps: this is a total function because a rotation is.

pub fn Image::rotate_by(self : Image, degrees : Double, expand? : Bool) -> Image raise Refused

The image turned clockwise by degrees.

expand grows the canvas to the rectangle the turned picture needs, which is what a caller rotating a photograph wants; without it the picture is turned inside the canvas it already had, and the corners are cut off, which is what a caller animating a rotation wants.

A multiple of ninety degrees is exact and is handed to rotate; nothing is resampled and no sample changes.

pub fn Image::row(self : Image, y : Int32) -> BytesView raise Refused

One row, without its padding.

pub fn Image::scale(self : Image, width : Int32, height : Int32, sampling? : Sampling) -> Image raise Refused

The image at a new size.

Raises when either dimension is not positive, and when the result would be larger than Limits::default() — a scaler is easy to point at a huge size by accident.

pub fn Image::to_premultiplied(self : Image) -> Image

The same image with colour multiplied by alpha.

Idempotent: an image that already says it is premultiplied comes back unchanged, so a caller can ask without checking first.

pub fn Image::to_straight(self : Image) -> Image

The same image with alpha divided back out.

The inverse of to_premultiplied up to rounding, which is why a round trip is only exact for images whose colour is already premultiplied.

pub fn Image::unsharp_mask(self : Image, radius? : Double, amount? : Double, threshold? : Int32) -> Image

The image sharpened by subtracting a blurred copy of itself.

amount is a percentage, a hundred being the difference added once: an edge that the blur softened is pushed back out by the same distance it lost. threshold is how much of a difference, in eight-bit steps, is worth sharpening at all, so that the grain of a photograph is not sharpened into noise. Sharpen with radius 1, amount 150 and threshold 3 is the usual starting point.

pub fn Image::upright(self : Image, code : Int32?) -> Image raise Refused

The image the right way up, given the orientation tag a file carried.

None is a file that said nothing, which is the same as saying one: a picture without a tag is a picture as stored.

enum pub(all) enum Kernel

How a blur is worked out.

  • Exact The kernel itself: every sample within three sigma, weighted by the Gaussian, convolved in two passes.
  • Boxes Three box passes per axis, whose sides are chosen so that the three together have the variance of the Gaussian asked for. This is what Pillow, Skia and most drawing systems do: a box pass is an addition and a subtraction per sample, and three of them are within a step of a sample of the kernel everywhere.
struct pub(all) struct Limits

The ceilings a decoder works under.

The defaults are the ones a desktop application can live with: a texture no larger than a modern GPU takes, and a megabyte of pixels at the very most. A caller reading files from the network should set them lower; a caller reading its own assets can leave them alone.

  • widthInt32 The widest image accepted, in pixels.
  • heightInt32 The tallest image accepted, in pixels.
  • pixelsInt32 The most pixels accepted, whatever the shape: this is the one that stops a long thin image from slipping past the two above.
  • bytesInt32 The most bytes a decoder may produce while unpacking: a compressed stream can expand without limit, so the expansion is capped separately.

error pub(all) suberror Refused

A refusal to read bytes as an image, or to write an image as bytes.

The variants separate the three questions a caller asks: is this the wrong kind of file (Unknown), is the file damaged (Unexpected, Truncated, Checksum), or is the caller asking for more than it allowed (OverLimit). Unsupported is the fourth: a part of a format this library does not read.

  • Unexpected(at~ : Int32, got~ : String, want~ : String) The bytes at at are not allowed here; want says what is.
  • Unknown(at~ : Int32, got~ : String) Nothing at at is an image this library reads.
  • Unsupported(at~ : Int32, got~ : String) A part of the format this library does not read.
  • Truncated(at~ : Int32, want~ : Int32) The bytes end want short of where the format needs them.
  • OverLimit(limit~ : Int32, got~ : Int32) A size or a length past what the caller's Limits allow.
  • Checksum(at~ : Int32, got~ : String, want~ : String) A checksum that does not match the bytes it covers.

enum pub(all) enum Sampling

How a scaler decides what an unknown pixel is worth.

  • Nearest The nearest pixel, and nothing else: no new colours.
  • Bilinear A weighted average of the two nearest, weights linear in distance.
  • CatmullRom A weighted average of the four nearest per axis, weights from the cubic with a = −0.5, which is the one that interpolates and does not overshoot much.
  • Gaussian A weighted average around the point, weights from a Gaussian with σ = 0.5 truncated at three sigma. No ringing at all, at the cost of a softer edge than the cubic or the windowed sinc.
  • Lanczos A weighted average of the six nearest per axis, weights from the Lanczos window with a = 3.

enum pub(all) enum Block

Which block format a texture is in.

  • Bc1 BC1: two colours and two thirds of the way between them, with a transparent entry in the three-colour form.
  • Bc1Opaque BC1 with alpha treated as opaque, which is how a normal map is stored.
  • Bc2 BC2: four bits of alpha a pixel, then a BC1 colour block.
  • Bc3 BC3: interpolated alpha, then a BC1 colour block.
  • Bc4 BC4: one channel, interpolated from two endpoints.
  • Bc5 BC5: two channels, each a BC4 block.
  • Bc6h BC6H: three channels of half-precision light, unsigned.
  • Bc6hSigned BC6H with signed samples, which is what a difference between two exposures is stored in.
  • Bc7 BC7: eight bits a channel, with a mode number that says how the block is divided.

exr OpenEXR

enum pub(all) enum Compression

How a chunk of scanlines was packed.

  • None As they are.
  • Rle A byte-oriented run-length code.
  • Zips Deflate, one scanline to a chunk.
  • Zip Deflate, sixteen scanlines to a chunk.
  • Piz A bitmap of the words used, a wavelet, and a Huffman code.
  • Pxr24 Twenty-four bits of every sample, split by significance and differenced.
  • B44 Blocks of four by four halves, fourteen bytes each: four bits of a sample kept, everything below them dropped.
  • B44a The same, with a block of one value written in three bytes instead.
  • Dwaa Eight-by-eight blocks of a picture turned into frequencies and quantized, thirty-two scanlines to a chunk.
  • Dwab The same with two hundred and fifty-six scanlines to a chunk, which suits a photograph better and a strip of a tiled render worse.

enum pub(all) enum Filter

Which row filter an encoder uses.

Adaptive is the one the specification recommends: try all five, keep the one whose output has the smallest sum of absolute differences. It costs four extra passes over each row and usually pays for itself several times over in what the compressor then has to store.

  • Adaptive Pick per row.
  • None Store the row as it is.
  • Sub Subtract the pixel to the left.
  • Up Subtract the pixel above.
  • Average Subtract the average of the two.
  • Paeth Subtract the one the Paeth predictor picks.

The alpha plane that travels beside a lossy picture.

VP8 codes no alpha, so a transparent lossy WebP carries a separate ALPH chunk: one byte saying how it is stored, then the plane — raw, or compressed with the *lossless* codec, in which case the samples sit in its green channel — then a filter along each row, the same idea as PNG's and undone the same way.
